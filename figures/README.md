# Figure Source Data

This directory contains lightweight source-data CSV files for the manuscript figures where aggregate numeric values are reported.

## Files

- `figure_source_index.csv`: figure titles and source-data notes.
- `figure2_hotpot32_f1.csv`: fixed routing and evidence-priority rerouting F1 on the HotpotQA 32-query subset.
- `figure3_rerouting_delta_f1.csv`: evidence-priority rerouting delta F1 values reported for HotpotQA Real-300.
- `figure4_two_passage_identifier_counts.csv`: selected two-passage identifier counts.
- `figure5_cross_task_prag_combine_f1.csv`: PRAG/Combine F1 across controlled benchmark subsets.
- `figure6_2wiki_same_source_metrics.csv`: EM/F1/precision/recall on the 2Wiki same-source subset.
- `figure7_supplementary_diagnostics.csv`: supplementary aggregate values for 2Wiki, Hotpot context-only control, and Hotpot subtask breakdown.

The original figure images are uploaded separately to the journal system. This directory provides auditable numeric source data and reconstruction notes.
