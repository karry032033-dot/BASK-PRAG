# Core Code Excerpts

This directory contains compact, dependency-light code excerpts for inspecting the core BASK logic. The scripts are intended for reproducibility review and smoke testing, not as a full production implementation.

## Files

- `bask_core_minimal.py`: reference implementation of coverage-aware grouping, sparse route-preserving invocation, simple QA metrics, bootstrap confidence intervals, and posterior synergy auditing.
- `original_framework_core/`: optional location for selected implementation files from the full experimental framework.
