# Table Source Data

This directory contains lightweight CSV source data for the manuscript tables. The files are intended to support auditing of aggregate values reported in the review PDF.

## Files

- `table1_construction_cost_profile.csv`
- `table2_implementation_settings.csv`
- `table3_two_passage_candidate_cache_audit.csv`
- `table4_dyprag_main_comparison.csv`
- `table5_dyprag_cost_latency_summary.csv`

Large per-query predictions, retrieval traces, and full run directories are not redistributed here. If released later, they can be placed in `predictions/`, `retrieval_logs/`, or `adapter_logs/`.
